# Module 04 — Operators

Operators are symbols and keywords that allow JavaScript to perform
operations on values and variables.

They are fundamental to programming because they allow us to calculate,
compare, assign, evaluate conditions, and make decisions.

---

## 🎯 Learning Objectives

By the end of this module, I should be able to:

- Explain what an operator is
- Use arithmetic operators
- Perform calculations using variables
- Use assignment operators
- Compare values using comparison operators
- Understand strict and loose equality
- Use logical operators
- Understand the difference between `&&`, `||`, and `!`
- Use increment and decrement operators
- Use the conditional/ternary operator
- Understand operator precedence
- Combine multiple operators in expressions
- Evaluate real-world programming conditions
- Apply operators to pharmacy-related problems

---

# 📚 Topics

## 1. Arithmetic Operators

- Addition `+`
- Subtraction `-`
- Multiplication `*`
- Division `/`
- Remainder `%`
- Exponentiation `**`

---

## 2. Assignment Operators

- Assignment `=`
- Addition assignment `+=`
- Subtraction assignment `-=`
- Multiplication assignment `*=`
- Division assignment `/=`
- Remainder assignment `%=`
- Exponentiation assignment `**=`

---

## 3. Comparison Operators

- Equal `==`
- Strictly equal `===`
- Not equal `!=`
- Strictly not equal `!==`
- Greater than `>`
- Less than `<`
- Greater than or equal `>=`
- Less than or equal `<=`

---

## 4. Logical Operators

- AND `&&`
- OR `||`
- NOT `!`

---

## 5. Increment and Decrement

- Increment `++`
- Decrement `--`
- Prefix increment
- Postfix increment
- Prefix decrement
- Postfix decrement
