# Module 01 - JavaScript Basics

## 1. What is Javascript?

JavaScript is a programming language used to create interactive and dynamic
softwares.

It is commonly used for:

* Web development
* Backend development
* Mobile application
* Desktop application
* APIs
* Browser-based applications

## Where JavaScript runs

JavaScript can run in different environments

### Browser

Browsers contain JS engines that execute JS code

* Google Chrome (V8)
* Firefox (SpiderMonkey)
* Safari (JavaScriptCore)

### Node.js

Node.js allows JS to run outside the browser.

It can be used for:

* Command-line programs
* Backend servers
* APIs
* Development tooling
* Packaged managemnt
